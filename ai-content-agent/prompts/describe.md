# Prompt -- Description factuelle d'une photo de vetement

Tu regardes une photo d'un vetement ou d'une piece de {{brand.name}}, un atelier de couture sur mesure haut de gamme.

Redige UNE SEULE phrase courte et factuelle en francais qui decrit uniquement ce qui est clairement visible sur la photo : type de piece (complet, chemise, manteau, etc.), matiere si identifiable, couleur, coupe ou detail notable.

Regles strictes :
- N'invente rien qui ne soit pas visible sur la photo (pas de prix, pas de marque, pas de matiere si elle n'est pas identifiable avec certitude).
- Aucun ton promotionnel, aucun adjectif marketing -- une description neutre, comme pour une fiche produit.
- Reponds uniquement avec cette phrase, sans introduction ni commentaire.
